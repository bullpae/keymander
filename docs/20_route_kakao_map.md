# 20. `:map` (`:길`) — 카카오맵 길찾기로 넘기기

> 상태: 구현 (2026-10-24, 브랜치 `bullpae/route`). 코드: `crates/kmd-core/src/route.rs`, 현재 위치 `crates/kmd-daemon/src/location.rs`

## 1. 왜

컴퓨터 앞에서 가장 자주 묻는 것 중 하나가 "여기서 거기까지 대중교통/차로 얼마나"다.
경로 계산·화면·실시간 교통은 카카오맵 웹이 이미 잘한다. 런처는 **목적지를 치면
그 경로 화면을 바로 여는 것**까지만 맡는다. (NextMove 는 폰 앱이고 외부에서 경로를
받는 입구가 없다 — 폰으로 넘기기는 NextMove 쪽 계약이 생긴 뒤의 일이다.)

## 2. 쓰는 법

```
:map                    사용법 + 내 장소 목록 (기본 출발지 → 각 장소)
:map 판교역             기본 출발지 → 판교역 (대중교통)
:map 차 회사 → 강남역    출발지 지정, 수단 지정
:길 회사에서 집          한글 별칭 · "에서" 로도 구분
:route walk 서울역       영문 별칭
```

- 명령어는 `:map` 이 기본이다 — 영문 자판 그대로 칠 수 있게. `:길`·`:route` 도 같다.
  (`@map` 은 원래부터 구글 지도 검색이라 건드리지 않는다.)
- 수단 낱말(맨 앞): 대중교통·버스·지하철 / 차·자동차·자가용 / 도보·걸어 / 자전거 (영문 transit·car·walk·bike).
  안 적으면 대중교통. 내 장소끼리이고 수단을 안 적으면 네 수단을 모두 한 줄씩 보여 준다.
- 출발·도착 구분: `→`, `->`, `>`, `에서 `.
- Enter = 카카오맵 길찾기 화면을 브라우저로 연다.

## 3. 좌표가 필요한 이유와 세 갈래

카카오맵 웹은 **이름만으로는 경로를 열지 않는다** (`?sName=&eName=` 같은 옛 형식은 지금 무시되고,
`/link/by/.../이름/이름` 도 빈 화면). 좌표를 넣은 `/link/by/{traffic|car|walk|bicycle}/이름,위도,경도/이름,위도,경도`
만 경로 화면으로 302 된다 (2026-10-24 확인).

| 경우 | 동작 |
|---|---|
| 내 장소(config) | 좌표가 있으니 바로 길찾기 링크 |
| 처음 가는 곳 + 카카오 키 있음 | 카카오 로컬 키워드 검색으로 후보 7곳(거리 표시) → 고르면 길찾기 |
| 키 없음 | 카카오맵 장소 검색 화면 (`/link/search/…`) — 거기서 "도착" |
| 출발지를 정하지 않음 | `/link/to/…` — 도착만 채운 길찾기(출발지는 카카오맵에서) |

### 3.1 기본 출발지 = 현재 위치

출발지를 안 적으면 **현재 위치**에서 출발한다 (`use_location = true`, 기본). `여기`·`현재위치` 낱말로도 부른다
(`:길 회사 → 여기`).

- 데몬이 OS 위치 서비스(주변 Wi-Fi 기반, 수십 m)로 재고 **메모리에만** 둔다 — 디스크에 남기지 않는다.
  런처는 단축키마다 새로 뜨므로 매번 재면 1~3초가 걸려서, 데몬이 60초 안의 값은 그대로 주고,
  새로 재다 실패하면 30분 안의 값을 대신 준다. IPC `Request::Location`.
- Windows: `Windows.Devices.Geolocation`. 설정 > 개인정보 및 보안 > 위치에서 "위치 서비스"와
  "데스크톱 앱의 위치 접근 허용"이 켜져 있어야 한다.
- macOS: CoreLocation. 처음 한 번 "위치 접근 허용" 창이 뜨고 권한은 `kmd-daemon` 에 붙는다.
  `.app` 꾸러미가 아니라서 `build.rs` 가 실행 파일에 Info.plist(번들 ID `com.keymander.kmd-daemon`,
  사용 목적 문구)를 넣는다.
- 위치를 못 얻으면(권한 거부·Wi-Fi 꺼짐·데몬 없음) 결과 맨 위에 이유를 보이고 `origin` 에서 출발한다.
  `origin` 도 없으면 도착만 채운 길찾기를 연다.
- 결과 줄은 "현재 위치 → 판교역", 카카오맵 출발지 이름도 "현재 위치".
- 위치가 고정된 데스크톱은 `use_location = false` + `origin = "집"`.

데스크톱은 장소 검색을 워커에서 하고, 입력이 300ms 멈춘 뒤에만 호출한다(그 사이 새 입력이면 건너뜀).
TUI 는 키마다 네트워크를 기다릴 수 없어 내 장소와 장소 검색 링크만 낸다.

## 4. 설정

```toml
[launcher.route]
# use_location = true              # 기본 — 출발지를 안 적으면 현재 위치
origin = "집"                      # 현재 위치를 못 얻었거나 use_location = false 일 때
# kakao_key_file = "~/.config/nextmove/kakao.env"   # 기본값

[launcher.route.places]
집 = "37.4979,127.0276"            # 위도,경도 (거꾸로 적어도 고친다)
회사 = "37.3948,127.1112"
```

좌표는 카카오맵에서 장소를 우클릭 → "이 위치의 주소/좌표" 등으로 얻는다.

## 5. 카카오 키·약관

- 키: 환경 변수 `KAKAO_REST_API_KEY` → 없으면 `kakao_key_file`(기본 `~/.config/nextmove/kakao.env`,
  NextMove 와 같은 파일)의 `KAKAO_REST_API_KEY=` 줄. 바이너리에 넣지 않는다.
- 호출은 OS 기본 `curl`(macOS, Windows 10+)로 한다 — HTTP·TLS 의존성을 늘리지 않는다.
  키는 프로세스 목록에 보이지 않게 표준 입력의 curl 설정(`-K -`)으로 넘긴다.
- 카카오 약관은 응답의 저장·캐시를 금한다. 검색 결과는 화면에만 두고, 항목을 열어도
  URL 열기라 실행 이력(frecency)에 남지 않는다. 손버릇 통계에도 목적지는 남지 않는다.
- 키워드 검색 무료 한도는 넉넉하다(일 10만 건 수준). 경로 API(`publictraffic`, 일 1천 건)는 쓰지 않는다.
